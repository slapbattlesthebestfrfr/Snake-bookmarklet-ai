iPad (Safari)

  1. Tap Copy code below.
  2. Bookmark this page (Share → Add Bookmark), name it “Snake”.
  3. Open Bookmarks → Edit, tap the “Snake” bookmark, replace its address with the copied code, Done.
  4. On any page, open Bookmarks and tap “Snake”.

Play: arrows/WASD or swipe. Space pauses, R restarts, Esc or tapping outside the window closes.
